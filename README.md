# JEE Mistake Notebook

GitHub Pages-ready frontend for the JEE Mistake Notebook.

## Deploy with GitHub Pages

1. Upload all files in this folder to the root of a GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save and wait for GitHub Pages to publish.

The app's local/offline data is stored in the browser. The Google Cloud backend is not deployed by GitHub Pages.
